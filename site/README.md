# Fisco API Landing Page

Landing page estática para GitHub Pages.

## Publicar no GitHub Pages

1. Suba estes arquivos para o repositório.
2. Vá em `Settings > Pages`.
3. Em `Build and deployment`, selecione:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root` ou `/docs`, conforme onde você colocou os arquivos.
4. Salve e aguarde a URL do GitHub Pages.
